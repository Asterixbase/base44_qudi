1. Member Onboarding Flow

Splash → Register → KYC → Phone Verify → Terms → Dashboard

Outcome: User created, KYC verified, ready to join circles

2. Collection → Payout Cycle (Core Loop)

Collection Phase

Organiser: Circle Detail → Collect Dues

System fetches pending members, organiser confirms via PIN

Simulates/executes MoMo collection requests

Transactions.create() with type: collection, status: success/failed

Collection Monitoring

Collection Monitor auto-checks every 30s vs 70% threshold

If below 70% → Alert + Urgency Blast button

Admin sends SMS/in-app alerts to unpaid members

⚠️ sendUrgencyBlast() logs to Notification entity

Smart Payout Gate

Smart Payout Scheduler validates 80% collection threshold

Gross pot = collections − pending penalties

Circle shows "Ready" or "Waiting for X%" countdown

Payout Execution

Admin: Payout Distribution or Scheduler

Determines recipient (random/fixed/rotation/bid), applies penalty deductions

Security checks (ID match, MoMo match), PIN auth, executes transfer

Transactions.create() with type: payout, momo_ref, status: success/failed

Reconciliation & Settlement

Admin runs Reconciliation page to match MoMo logs vs ledger

System flags unmatched transactions for manual review

Completes cycle when all payouts confirmed

3. Risk Management

Trust Score (0-100)

Base: Payment success rate × 80

+ 10 if KYC verified

− 5 per penalty

Updated on Member Profile

Penalty System

Auto-trigger: If payment overdue

Type: flat_fee / percentage / daily_interest

Grace period + guarantor notification

PenaltyLedger tracks settlement status

Guarantor Health

Aggregates all guaranteed members

Risk score = avg trust + payment rate + penalties

Flag high-risk guarantors (Admin only, role guard enabled)

4. Dispute & Insurance

Dispute Submission

Member reports: payment status / fraud / missed payout

Provides proof URL

Dispute.create() → status: open

Escrow & Review

Admin reviews evidence

If legitimate → escrow_held = true, funds locked

Status: open → under_review → escrow_held

Resolution

Admin applies action: release escrow + reimburse or penalize organiser

Close dispute + member notification

Insurance Claims

Member submits claim (missed payout / fraud / hardship)

Insurer approves/rejects → payout if approved

InsuranceClaim tracks status, claim_ref, payout

5. Cross-Border Payout Flow (New)

Select Country → Enter GBP → Convert to GHS → Calc FCA Fee → Review → Submit & FCA Ref

Exchange Rates: UK £1 = GHS 11.5 | US $1 = GHS 15.2 | EU €1 = GHS 12.8 | AUS $1 = GHS 10.2

FCA Compliance: Flat fee + 1% (UK), capped at £25 max

CrossBorderPayout entity with status: pending → approved → processing → completed
